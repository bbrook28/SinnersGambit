# The Bag Hand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the hand's rules, policies, tests and sim around the bag hand, so the sim reports it against the pass marks.

**Architecture:** The rules are rewritten in place in `hand/`. They stay UI-free static functions in `rules.gd` over plain data in `hand_state.gd`, with every number in `config.gd`. `play.gd` drives a hand with a policy, `policies.gd` holds random, greedy, push and strong, and `sim/hand_sim.gd` reports. The first hand's code stays in git history (up to 9a0053e). Its trial options (`target_max`, `open_prizes`, `prizes_after_target`) and its threats, rerolls and countdowns are removed.

**Tech Stack:** Godot 4.7.2 GDScript, headless (`--script`); `preload` consts, never `class_name`.

**Spec:** `docs/superpowers/specs/2026-11-20-bag-hand-design.md` (with `2026-11-20-core-hand-design.md` for the pass marks).

## Global Constraints
- Every number is a `hand/config.gd` DEFAULTS key; the sim overrides any key with `key=value`.
- The rng is duck-typed: the rules only call `rng.randi_range(a, b)`, so tests pass a FixedRng.
- Commit only named files, never `git commit -a`, never `project.godot`. Push nothing.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tests: `bash tests/run_all.sh` prints `ALL PASSED`.

## Decisions this plan makes (the spec leaves them open)
- **A Ward-cancelled skull** goes back into the bag. The Ward's two dice leave the hand. The Ward can be filled again.
- **A held die placed on the Dance** is not doubled. Only the thrown Dance die is doubled.
- **A full Ladder doubles** every later die into the Target, the held die included. Doubling stacks with the Dance (×4).
- **The order rng calls are made in:**
  - **Layout:** engine kinds by `pop_at(randi_range(0, n-1))` from `engine_pool`, then the prize kind by the same from `prize_pool`, then the starting wire by the same from `wire_pool`.
  - **Throw:** the handful's faces first, then each cursed die, in slot order.
- **Pace verdict:** strong's throws a hand fall in 6.0–7.0.

## Review Focus
- **A hand where every throw is skulls.** Nothing is placed, the Master still answers, and the hand ends by bust or by an empty bag, never by a stuck loop. Owned by Task 4: `test_all_skulls_ends`.
- **Hold with the bag empty.** The one last placement happens once, then a cash-out. Owned by Task 4: `test_last_placement`.
- **Tax firing after the Target is met.** The hand can become short again, while the revealed prize stays revealed and Hunger stays on. Owned by Task 3: `test_tax_unmeets`.
- **Curse on a lone 6 in the Ladder.** It returns to the bag, and the bag count goes up by one. Owned by Task 2: `test_curse_ladder_six`.
- **A hand dealt Hold and one 2-die slot, where Tax is the second wire after Hold is seeded.** Tax lands on the other slot. Owned by Task 3: `test_tax_lands_on_two_die_slot`.

### Task 2: The throw: draw, skulls, Ward, Dance, Hunger, Curse

**Files:** Modify `hand/rules.gd`, `tests/hand_test.gd`.

**Interfaces:**
- Consumes: Task 1's state and slots.
- Produces: `Rules.throw(s, rng) -> Array[int]`, which returns the non-skull faces thrown.
  1. Draw `n = min(hunger_handful if hunger_on else handful, bag)`, then `bag -= n`.
  2. Hunger switches on (`hunger_on = true`, latched) at the start of a throw, when a Hunger wire is dealt and the Target is met.
  3. `dance = (n == 1 and the bag was 1)`; `dance_reached` latches.
  4. Each face ≤ `skull_faces` is a skull.
  5. With a Curse wire dealt, every die alone in a Hold, Ward or Ladder rethrows after the handful. The order is slot order, with `randi_range(1, 6)`:
     - ≤ `curse_skull_faces`: a skull (it leaves the slot) and `curse_skulls += 1`;
     - a 6 alone in the Ladder: leaves the slot, and `bag += 1`;
     - otherwise: the die keeps its slot with the new face.
  6. Skulls land in order, handful first. While a Ward is full, the first skull is cancelled: Ward `dice = []`, `bag += 1`, `cancelled += 1`. Each other skull adds 1 to `skulls`.
  7. Bust when `skulls >= bust_at`, or on any uncancelled skull from the Dance die.
  8. `throws += 1`.
- Produces: `Rules.value(s, face, from_hold: bool) -> int`. Doubled on the Dance unless `from_hold`.

### Task 3: Placing and the Master's answer

**Files:** Modify `hand/rules.gd`, `tests/hand_test.gd`.

**Interfaces:**
- Produces: `Rules.legal_moves(s, faces: Array[int]) -> Array` of `{die:int, slot:int}`, where `die` -1 means the held die.
  - **Target and Offering** take any die.
  - **Hold** takes a die when it's empty. A held die can never go back into Hold.
  - **Ward** takes a die when it's empty, or when the die's face equals the waiting face.
  - **Ladder:** empty, it takes a value ≤ 5. With one waiting, it takes a value higher than the waiting value. The value includes Dance doubling.
  - **Prize** takes a die only when it's not hidden and not done. A Pair matches by face. A Sum's first die needs `need - v >= 2`, and its second must hit `need` exactly.
  - Moves for the held die are added when Hold has a die.
- Produces: `Rules.place(s, faces, move) -> void`.
  - **Target** adds `value`, doubled again if the Ladder is full.
  - **Offering:** `offerings += 1`.
  - **Engine and prize slots** append the die. A Ladder stores values; Ward and Pair store faces; a Sum stores values. A slot that reaches its cap gets `fills += 1`, and prizes become `done`.
  - The first die into an engine slot sets `seeded = true`, and the Master deals the second wire at the next `master_answer`.
  - **Afterwards:** unplaced faces return to the bag (`bag += faces.size() - 1`, or `faces.size()` when the held die was placed). On the Dance, an unplaced die leaves the hand instead.
  - If the Target is met, `revealed = true` (latched) and the prize is unhidden.
- Produces: `Rules.master_answer(s) -> void`.
  1. A Tax whose slot is full sets `tax_on` (latched). This step skips a wire dealt by this same call.
  2. If `seeded` and no second wire was dealt yet and `wire_pool` is non-empty, pop the next wire with `rng`-free order (pool order). If it's Tax, it goes on the slot just seeded when that's a Ward or Ladder, otherwise on the other Ward or Ladder.
- Produces: `Rules.target_met(s)` (`progress >= need(s)`, a live check), `Rules.cash_out(s)`, `Rules.ended(s)`, and `Rules.marks(s)` (`win_marks` plus a done prize's marks if won, else 0).

### Task 4: The play loop and the end of the bag

**Files:** Rewrite `hand/play.gd`; modify `tests/hand_test.gd`.

**Interfaces:**
- Produces: `Play.hand_rng(run_seed, i)` (unchanged) and `Play.play_hand(cfg, policy, rng) -> HandState`.
- Produces: `Play.play_from(s, policy, rng, answer_first: bool) -> HandState`. The loop:
  1. Throw.
  2. If not ended and there is a move, `policy.choose(s, faces, moves, rng)` and `place`.
  3. `master_answer`.
  4. If the bag is 0: when Hold has a die, offer `legal_moves(s, [])` (held moves only) to `choose` once and place it. Then `cash_out`.
  5. Else, if `policy.stop(s, rng)`, `cash_out`.
- A policy is `{name, choose: Callable(s, faces, moves, rng) -> move, stop: Callable(s, rng) -> bool}`. Rerolls are gone.

### Task 5: Policies

**Files:** Rewrite `hand/policies.gd`; modify `tests/hand_test.gd`.

**Interfaces:**
- **`random_policy()`:** any legal move. It stops 3 times in 10 once the Target is met.
- **`greedy_policy()` and `greedy_move(s, faces, moves) -> Dictionary`:** the baseline. It places the highest value into the Target (the held die counts if higher), and puts any die into the Offering only when no Target move exists. It stops as soon as the Target is met.
- **`push_policy()`:** the strong policy's playouts. Its rules, in order:
  - finish a half-filled engine slot or revealed prize when a die completes it;
  - seed the Ladder with its lowest die ≤ 3 while the Target is ≥ 8 short;
  - seed the Ward when two dice match;
  - else `greedy_move`.

  It throws on past the Target while the prize is revealed and not done, and `skulls < bust_at - 1`.
- **`strong_policy(rollouts)`, `strong_move` and `strong_stop`:** the same method as today, with the dedupe key `"%d|%d" % [value of the die or held face, slot]` and the decision record `{best, second, moves, met}`. Delete the reroll options.
