# Core Hand Simulation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A headless Godot simulation that plays the core hand thousands of times with three policies and reports outcome rates, skill gap, agony and pace against the design's pass marks.

**Architecture:** The hand's rules live in `hand/` as UI-free static functions over a plain state object, so a later screen calls the same code. Policies in `hand/policies.gd` choose moves through the same rules API. `sim/hand_sim.gd` is a `SceneTree` script that parses `key=value` overrides, runs the policies and writes a report.

**Tech Stack:** Godot 4.7.2 (standard build), GDScript, headless `--script` runs.

**Spec:** `docs/superpowers/specs/2026-11-20-core-hand-design.md`

## Global Constraints
- Godot console exe: `G="$LOCALAPPDATA/Microsoft/WinGet/Packages/GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe/Godot_v4.7.2-stable_win64_console.exe"`.
- Scripts use `preload` consts, never `class_name`, so headless `--script` runs work without an editor import.
- Nothing in `hand/` touches nodes, scenes or UI.
- Every number in the rules is a key in `hand/config.gd` `DEFAULTS` and overridable from the sim's command line (`key=value`).
- All randomness goes through a passed `RandomNumberGenerator`, seeded, so a run is reproducible.
- Commit locally after each task with `git add <files>` naming files explicitly; never `git commit -a`; never commit `project.godot`; never push.
- Commit attribution line: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. A throw of all skulls (no die to place): no placement happens, the Master still answers, play continues or busts. Test in Task 3.
2. A strike that brings skulls to 3 busts during the Master's answer, before any further throw. Test in Task 3.
3. The Offering with no countdown on the table is still a legal place for a die (bump nothing). Test in Task 3.
4. A Last Dance die meets thresholds and sums at double value but fills a pair only by its face. Test in Task 3.
5. A rerolled die that comes up a skull stays on the table and can bust. Test in Task 2.

### Task 2: Throwing, skulls, bust, the Last Dance and the reroll

**Files:**
- Modify: `hand/rules.gd`
- Modify: `tests/hand_test.gd`

**Interfaces:**
- Consumes: Task 1.
- Produces:
  - `static func throw(s: HandState, rng: RandomNumberGenerator) -> Array[int]`: the non-skull faces thrown. Throws `s.in_hand` dice; a face `<= cfg.skull_faces` is a skull: `s.skulls += 1`, `s.in_hand -= 1`. Sets `s.dance_reached` when `in_hand` was 1 before the throw. Bust (`outcome = "bust"`) when `skulls >= bust_at`, or on a Last Dance skull. `s.throws += 1`.
  - `static func is_dance(s: HandState) -> bool`: returns `s.dance`, which `throw` sets.
  - `static func value(s: HandState, face: int) -> int`: `face * 2` when `s.dance`, else `face`.
  - `static func reroll(s: HandState, faces: Array[int], index: int, rng) -> Array[int]`: needs `s.rerolls > 0`; spends one; rethrows `faces[index]`; a skull result follows the throw rules (adds a skull, leaves the hand, may bust) and is removed from the returned faces.

  - `test_dance_doubles_and_busts`: `in_hand = 1`, queue `[3]` → `[3]`, `is_dance` true, `value(s, 3) == 6`; a fresh state with `in_hand = 1`, `skulls = 0`, queue `[1]` → `outcome == "bust"`.

### Task 3: Placing, the Master's answer, cashing out and marks

**Files:**
- Modify: `hand/rules.gd`, `tests/hand_test.gd`

**Interfaces:**
- Consumes: Tasks 1-2.
- Produces:
  - A move Dictionary: `{"die": int, "slot": int, "bump": int}` (`die` indexes the faces array; `bump` is the slot whose countdown the Offering raises, `-1` for none).
  - `static func legal_moves(s: HandState, faces: Array[int]) -> Array`: every legal move; empty only when `faces` is empty. Legality: Target and Offering take any die; threat and reroll need `value >= need`; pair takes a die when empty or when `face` equals the face already there; sum takes a first die when `need - value >= 2` and a second when the two values sum to exactly `need`; done slots take nothing. Offering moves enumerate `bump` over every live slot with a countdown, or one move with `bump = -1` when there is none.
  - `static func place(s: HandState, faces: Array[int], move: Dictionary) -> void`: puts the die in; `in_hand -= 1`; Target adds `value` to `progress`; threat is `done` (stopped); a full pair or sum is `done` (claimed); a reroll slot is `done` and `rerolls += 1`; Offering raises `slots[bump].countdown` by 1.
  - `static func master_answer(s: HandState) -> void`: each live, not-done slot with `countdown > 0` drops by 1; at 0 a threat strikes (`skulls += 1`, `gone = true`) and a prize is taken (`gone = true`, its dice lost). Gone slots take no dice and never tick. A strike reaching `bust_at` sets `outcome = "bust"` at once.
  - `static func target_met(s) -> bool`, `static func cash_out(s) -> void` (sets `"won"` or `"short"`), `static func marks(s) -> int` (0 unless won; then `win_marks` + `marks` of each pair/sum slot `done` and not `gone`).
  - `static func ended(s) -> bool`: `outcome != ""`; `place` calls `cash_out` itself when `in_hand == 0` (automatic cash-out).
- [ ] **Step 1: Write failing tests:**
  - `test_threshold_and_dance` (Review Focus 4): threat `need 5`; face 3 not legal; with `s.dance = true` face 3 legal; pair holding a 4 accepts face 4 but not face 2 even when doubled to 4.
  - `test_sum_exact`: sum `need 8`: first 3 legal, then second 5 legal and 4 not; first 7 not legal (`8 - 7 < 2`).
  - `test_offering_without_countdowns` (Review Focus 3): a table where no slot has a countdown → exactly one Offering move per die, `bump == -1`.
  - `test_all_skulls_answer` (Review Focus 1): faces `[]` → `legal_moves` empty; `master_answer` still ticks a threat from 2 to 1.
  - `test_strike_busts` (Review Focus 2): `skulls = 2`, threat at countdown 1 → after `master_answer`, `outcome == "bust"`.
  - `test_marks`: target met plus one claimed pair (marks 2) and one prize gone → `cash_out` gives `"won"`, `marks == 3 + 2`; a bust gives 0.
  - `test_auto_cash_out`: placing the last die in hand ends the hand with `"won"` or `"short"`.
- [ ] **Step 2: Run** the suite. Expected: the new tests FAIL.
- [ ] **Step 3: Implement** the functions above.
- [ ] **Step 4: Run** the suite. Expected: all PASS.

### Task 4: The driver and the random and greedy policies

**Files:**
- Create: `hand/policies.gd`, `hand/play.gd`
- Modify: `tests/hand_test.gd`

**Interfaces:**
- Consumes: Tasks 1-3.
- Produces:
  - A policy is a Dictionary of two Callables: `{"choose": func(s, faces, moves, rng) -> Dictionary, "stop": func(s, rng) -> bool}` plus `"name": String`. `choose` may return `{"reroll": index}` instead of a move when `s.rerolls > 0`.
  - `play.gd`: `static func play_hand(cfg: Dictionary, policy: Dictionary, rng) -> HandState` loops: throw; if not ended and faces non-empty, `choose` (handle a reroll answer, then choose again) and `place`; if not ended, `master_answer`; if not ended, ask `stop` and `cash_out` on true. Returns the final state. The strong policy fills `s.decisions`; the others leave it empty.
  - `policies.gd`: `static func random_policy() -> Dictionary` (uniform legal move; stop with probability 0.3 once the Target is met, never before), `static func greedy_policy() -> Dictionary` (highest-value die: into an unfinished threat it meets whose countdown is 1, else into the Target until met, else into any prize it fits, else the Target; stop as soon as the Target is met).

### Task 5: The strong policy

**Files:**
- Modify: `hand/policies.gd`, `tests/hand_test.gd`

**Interfaces:**
- Consumes: Tasks 1-4.
- Produces: `static func strong_policy(rollouts: int) -> Dictionary` (`name "strong"`). For each legal move (and each reroll option), clone the state, apply it, run `rollouts` greedy-continuation playouts with `play.gd`'s loop starting from the Master's answer, and take the move with the highest mean marks. `stop` compares the marks of cashing out now with the mean marks of `rollouts` greedy playouts that throw on. Each placement appends `{"best": float, "second": float, "moves": int}` to `s.decisions` (second is `best` when only one move exists).

`rollouts` comes from config key `rollouts` (default 64).

### Task 6: The sim script and its report

**Files:**
- Create: `sim/hand_sim.gd`
- Modify: `CLAUDE.md` (a Commands section with the sim and test commands)

**Interfaces:**
- Consumes: Tasks 1-5.
- Produces: `godot --headless --path . --script res://sim/hand_sim.gd -- [hands=2000] [strong_hands=500] [seed=1] [key=value ...]`. Writes the report to stdout and to `build/sim/hand_<seed>.txt`.

Report, one block per policy then a verdict block:
- won / short / bust %, Last Dance reached % and survived % (of reached), mean marks, mean throws.
- Strong only: agony = share of decisions with `moves >= 2` and `(best - second) <= 0.05 * best`.
- Verdict lines, each `PASS` or `MISS` with the number: strong minus greedy win rate `>= 10` points; greedy win rate above random's; agony `>= 30%`; strong's bust rate within 20-35%; strong's Last Dance reached within 15-30%.
- The config used, as `key=value` on one line, so any run can be repeated.
